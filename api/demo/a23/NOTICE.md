# SDS demo A2.3 package (sds-demo-a23-v1)

This package reproduces the public A2.3 verification (V1-V6) of the SDS
prototype. All values are synthetic demonstration data for the fictitious
NordHaven group; they are not company records.

ESRS datapoint names and descriptions (E1-5 and E1-6) are reproduced
verbatim from EFRAG's ESRS Set 1 materials (IG3 list of datapoints).
Source: EFRAG. GRI disclosures are referenced only by code (GRI 305) with
SDS-authored labels. Refer to the official ESRS and GRI publications for
normative definitions. Nothing here states or implies an endorsement by
EFRAG or GRI or an official equivalence between standards.

The three ESRS-to-GRI assertions are demonstration assertions approved by
the SDS operator for this package (see approval.json). The calculation
contract covers only the E1-5 energy consumption and mix model.
