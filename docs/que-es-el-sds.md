# ¿Qué es el SDS? (explicación para principiantes)

> Introducción en lenguaje sencillo, pensada para quien se acerca por primera vez
> al proyecto. Para la verdad técnica del producto y el estado de evidencia,
> consulta el [README](../README.md).

Imagina una biblioteca que comparten varias empresas. Cada una sigue siendo dueña
de sus datos y decide qué presta y a quién, pero todas se entienden porque hay una
gobernanza con reglas claras de acceso y uso. Eso es un espacio de datos.

El **SDS** (*Sustainability Data Space*) es esa idea aplicada a la sostenibilidad:
información sobre medio ambiente, impacto social y buen gobierno.

¿Para qué sirve? Para que esos datos sean fiables y fáciles de comparar entre
empresas, sin tanto papeleo.

Y como cada intercambio se hace con su contrato, una empresa incluso puede cobrar
por compartir sus datos.
