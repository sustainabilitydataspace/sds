# Reporte responsable de vulnerabilidades

No abra vulnerabilidades de seguridad en GitHub Issues públicas.

## Canal privado

Para reportar una vulnerabilidad de SDS:

1. Use la función privada de GitHub Security Advisories / "Report a
   vulnerability" si GitHub la muestra para este repositorio.
2. Si esa opción no está disponible, contacte con Cambridge Business Initiatives
   S.L. por info@sustainabilitydataspace.com indicando que necesita un canal
   privado para un reporte de seguridad. No incluya detalles explotables en una
   Issue pública.

## Qué incluir

Incluya solo la información necesaria para reproducir y valorar el problema:

- versión, commit o URL revisada;
- componente afectado;
- pasos mínimos de reproducción;
- impacto esperado;
- mitigaciones conocidas;
- si el hallazgo afecta a una instalación local de evaluación o a otro entorno.

No incluya secretos, credenciales, tokens, datos personales, datos de cliente,
material de terceros sin permiso ni información contractual confidencial.

## Qué hacer mientras se tramita

- No publique detalles explotables hasta que exista una coordinación razonable.
- No pruebe contra sistemas de terceros sin autorización.
- No use SDS en producción salvo acuerdo separado por escrito y autorización
  operativa propia.
