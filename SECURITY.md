# Security Policy

Do not report suspected vulnerabilities through public GitHub Issues.

Use GitHub Security Advisories / "Report a vulnerability" if GitHub shows that
private reporting option for this repository. If it is not available, contact
Cambridge Business Initiatives S.L. at info@sustainabilitydataspace.com and ask
for a private security-reporting channel before sharing exploitable details.

See `docs/security-reporting.md` for the full responsible-disclosure guidance.
